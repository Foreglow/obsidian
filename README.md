# Foreglow Theme for Obsidian

A twilight-inspired dark theme for Obsidian using CSS snippets.

## Installation

### As a CSS Snippet

1. Open Obsidian Settings → Appearance → CSS Snippets
2. Click "Open folder" to open the snippets directory
3. Copy `foreglow.css` into that folder
4. Enable the snippet in the settings

### As a Theme

1. Open Obsidian Settings → Appearance → Themes
2. Click "Manage" to open the theme folder
3. Copy the entire folder into the themes directory
4. Select **Foreglow** from the theme list
